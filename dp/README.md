**BOJ2294 : 동전 2 (G5)**
해결 방법 : 있는 동전으로 작은 동전부터 큰 동전까지 갱신하면서, 최소로 드는 동전 개수로 교체하기
ex) 1로 걸리는 만큼 구하기 -> 1, 2, 3, 4, 5, 6
2로 교체하기 -> 1, 1, 2, 2, 3, 3
5로 교체하기 -> 1, 1, 2, 2, 1, 2
